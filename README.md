# EchoCrime — The Midnight Theft

A third-person 3D detective game set in Riverside Museum (React, TypeScript, Vite, React Three Fiber, Rapier, Zustand).

```
npm install
npm run dev      # http://localhost:5173 (or the port Vite prints)
npm run build
```

Controls: WASD move · Shift run · Mouse look · E inspect · Enter collect · Tab evidence · Esc close.

Status: built phase by phase. Done: museum, third-person detective with collisions, press-E investigation and evidence inventory, visual-quality pass on the Main Gallery (in progress).
Not built yet: timeline, audio forensics, AI reconstruction, theory board, accusation.
